# LapTimer

A lightweight, mobile-first stopwatch PWA with a very large LAP button.

## Features
- Start, pause, resume and reset
- Lap split and cumulative time
- Last lap and best lap indicators
- Persists stopwatch state and lap history in local storage
- Offline cache through a service worker
- iPhone standalone display metadata

## Enable GitHub Pages
1. Open the repository **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then Save.
5. Wait for the deployment to complete.

The site URL will be https://fswim.github.io/LapTimer/.

## Install on iPhone
Open the Pages URL in Safari, tap Share, then **Add to Home Screen**.

Note: This is a Progressive Web App, not a signed native iOS IPA. GitHub Pages requires a public repository on GitHub Free.
